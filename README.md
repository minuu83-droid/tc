# 현장 소모품 구매 시스템

## 기술 스택
- **프레임워크**: Next.js 14 (App Router)
- **스타일링**: Tailwind CSS
- **언어**: TypeScript
- **DB**: SQLite (Node.js 22+ 내장 `node:sqlite`)
- **인증**: 역할별 세션 기반 로그인

## 실행 방법

```bash
npm install
npm run dev
# http://localhost:3000 접속
```

## 테스트 계정

| 역할 | 아이디 | 비밀번호 | 회사 |
|------|--------|----------|------|
| 직영 | admin | admin123 | - |
| 사용협력사 | user1 | user123 | ABC 제조(주) |
| 사용협력사 | user2 | user123 | XYZ 산업(주) |
| 납품협력사 | supplier1 | sup123 | 우리공급(주) |
| 납품협력사 | supplier2 | sup123 | 최저가자재(주) |
| 납품협력사 | supplier3 | sup123 | 한국자재(주) |

## 발주 프로세스

1. **구매 요청** (직영/사용협력사)
   - 품목 사양/메이커 등록
   - 계약 품목이면 **자동 발주** 처리

2. **입찰** (납품협력사)
   - 납품 가능 단가 입력
   - 최저가 자동 표시

3. **낙찰 및 계약** (직영)
   - 최저가 업체 낙찰 처리
   - 계약 기간 설정 (이 기간 동안 자동 발주 활성화)

4. **발주 추적**
   - 발주완료 → 처리중 → 배송중 → 납품완료

## 주요 기능

- 대시보드: 발주현황, 입찰현황, 계약 만료 알림
- 구매 요청: CRUD + 자동발주 판별
- 입찰 관리: 최저가 하이라이트, 낙찰 처리
- 발주 현황: 상태별 필터, 납품 상태 업데이트
- 협력사 관리: 사용/납품협력사 분리 관리
- 품목 관리: 품목 코드/메이커/규격/계약 여부
- 계약 이력: 절감액 계산, 만료일 알림
